# Grading system

Create a `c` program that reads a student's score and prints the corresponding grade based on the following criteria:

Score Range | Grade
------------|------
0 - 39      | F
40 - 49     | E
50 - 59     | D
60 - 69     | C
70 - 79     | B
80 - 100    | A

>100        | X
<0         | X
Blank       | Y

The program should handle invalid inputs (scores less than 0 or greater than 100) by printing "X". If the input is blank, it should print "Y".
